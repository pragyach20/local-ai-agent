# 🤖 Local AI Agent

A Python-based conversational AI assistant built using LangChain and Google's Gemini API. The agent runs locally through the terminal and maintains conversation history during the active session.

## 🚀 Features

- Conversational AI assistant
- Gemini-powered responses
- Conversation memory during the active session
- Secure API key management using `.env`
- Clean terminal-based interface
- Error handling for API failures
- Simple and lightweight Python architecture

## 🛠️ Technologies Used

- Python
- LangChain
- Google Gemini API
- python-dotenv
